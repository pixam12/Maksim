📖 Jak uzyskać cookie? (Opera GX)
  1. Zaloguj się na vinted.pl w Opera GX
  2. Naciśnij Ctrl + Shift + I (otwiera DevTools)
    Alternatywnie: kliknij menu ≡ → Deweloper → Narzędzia deweloperskie
  3. Kliknij zakładkę Network (Sieć) u góry DevTools
  4. Odśwież stronę Vinted (Ctrl + R)
  5. Kliknij dowolny request (np. pierwszy z listy) do vinted.pl
  6. Po prawej znajdź sekcję Request Headers
  7. Znajdź pole Cookie i skopiuj całą jego zawartość
  8. Wklej tutaj i kliknij "Zapisz"
